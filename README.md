# Cipta Robo · NURI concept website

Interactive, mobile-friendly concept storefront for **NURI**, a modular AI companion imagined in Malaysia.

> **Concept only.** NURI is not for sale. Company branding, trademark status, prices, hardware specifications and timeline are not finalized.

## Features

- Responsive premium landing page for Cipta Robo / NURI
- Personality customization: Curious, Cheerful, Calm and Focused
- Editable companion name and use-case selector
- Optional accessory selections: shoulder dock, roller base, walking kit and drone vehicle
- Illustrative RM price calculator and copyable concept build
- Concept roadmap, safety and FAQ disclosures
- Single-file static HTML/CSS/JavaScript, no build or external dependencies

## Local preview

Open `index.html` in any modern browser. For a development server, run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publishing with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set branch **main**, folder **/(root)**, then save.
5. Wait for GitHub Pages to publish, then check the website URL shown on that Settings page. For a typical personal repo it will be `https://danialrohaizat012-sys.github.io/aicompanion/`, but verify before sharing.
